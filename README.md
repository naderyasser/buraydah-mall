# مول بريدة الإلكتروني

منصّة تسوّق لمحلات مدينة بريدة: منتجات بأسعارها من محلات مختلفة، **سلة واحدة**،
وطلب يُقسَّم تلقائياً على أصحاب المحلات. لا دفع إلكتروني في هذه المرحلة —
الدفع عند الاستلام أو مع المحل.

منشور على **https://buraydah.meena-alaqariya.com**

## التشغيل

```bash
npm install
psql "$DATABASE_URL" -f src/db/schema.sql
psql "$DATABASE_URL" -f src/db/migrations/002_visits_sales.sql
psql "$DATABASE_URL" -f src/db/migrations/003_products_orders.sql
psql "$DATABASE_URL" -f src/db/seed.sql           # محلات تجريبية
psql "$DATABASE_URL" -f src/db/seed_products.sql  # منتجات تجريبية
npm run build && sudo systemctl restart buraydah-mall
```

**تنبيهان:** PostgreSQL هنا على المنفذ **1337** لا 5432. و`nginx 1.24` على هذا
الصندوق لا يعرف `http2 on;`.

الإعدادات في `.env.local`: `DATABASE_URL`، `ADMIN_USERNAME`، `ADMIN_PASSWORD`،
`SESSION_SECRET`، `PUBLIC_COUNTER_MIN` (أدنى رقم يظهر عنده عدّاد الزوار للعموم)،
و`NEXT_PUBLIC_DEMO_BANNER=1` لشريط «نسخة تجريبية» — احذفه عند إدخال بيانات حقيقية.

## المسارات

| المسار | الوظيفة |
|---|---|
| `/` | الأجنحة + مختارات المنتجات + عدّاد الزوار العام |
| `/wing/<slug>` | منتجات الجناح ومحلاته |
| `/product/<slug>` | صفحة المنتج + بيانات Product المنظّمة |
| `/store/<slug>` | المحل: منتجاته وعنوانه ودوامه |
| `/cart` · `/checkout` · `/order/<code>` | السلة، الطلب، وتأكيده موزّعاً على المحلات |
| `/go/<slug>` | تحويل للمحل مع تسجيل النقرة (للمحلات بلا منتجات) |
| `/api/visit` | تسجيل زيارة واحدة لكل زائر يومياً |
| `/admin` | اللوحة: طلبات، منتجات، محلات، أجنحة، تقارير |

## قرارات مقصودة

- **الأسعار تُعاد قراءتها من القاعدة عند الطلب** ولا تُؤخذ من السلة أبداً؛ السلة
  تعيش في `localStorage` على جهاز الزائر فكل رقم منها غير موثوق.
- **الطلب يُقسَّم على المحلات** في `order_items` بحالة مستقلة لكل سطر، لأن كل محل
  يؤكّد نصيبه وحده — هذا واقع المول لا تفصيل تقني.
- **رقم الطلب يُولَّد بجملتين لا بـ CTE واحد**: في PostgreSQL لا ترى جملة `UPDATE`
  الصفَّ الذي أدرجه CTE في نفس العبارة، فيعود `RETURNING` فارغاً.
- **عدّاد الزوار يُسجَّل من المتصفّح** لا من الخادم، فيستبعد الزواحف ويعطي رقماً
  صادقاً؛ ولا يظهر للعموم قبل `PUBLIC_COUNTER_MIN`.
- **«عدد المشتريات» صار قابلاً للقياس** لأن الطلب يُنشأ داخل المنصة. جدول
  `store_sales` باقٍ لتسجيل مبيعات يؤكّدها التاجر خارج المنصة.
- **الترتيب = المنتج**: `featured` ثم `paid` ثم `sort_order` — هذا ما تُباع به
  المساحات المميّزة.
- **الصور**: **لا صور نساء إطلاقاً** — ولا حتى بالعباية أو اليدين أو مجسّم يُقرأ
  كامرأة. سوق القصيم لا يقبلها. الصور التجريبية كلها منتجات ومجسّمات عرض.
- **النموذج مزدوج**: الماركة بلا منتجات = دليل، والضغط على شعارها يحوّل لموقعها
  مباشرة (`/go/`) كما في مواصفات العميل؛ والماركة ذات المنتجات تبيع بسلة داخل
  المول. `BrandTile` هو ما يفرّق بينهما بحسب `product_count`.
- **`slug` لا يُغيَّر بعد النشر** — الروابط المنشورة تعتمد عليه.

## الاختبار

`playwright-core` مثبّت ويستخدم كروم النظام (`/usr/bin/google-chrome`) بلا تنزيل
متصفّحات. اختبار المسار الكامل: إضافة منتجين من محلين ← السلة ← الطلب ← صفحة
التأكيد ← تفريغ السلة.
